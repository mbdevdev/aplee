# 🍎 Яблоко

Интерактивный сайт про яблоко на React Three Fiber: происхождение, сорта, состав и факты.
Само яблоко **построено кодом** (сфера + деформации + раскраска вершин), в проекте нет ни одного 3D-файла и картинки.

## Запуск у себя

```bash
npm install
npm run dev      # http://localhost:5173
npm test         # проверки геометрии и поведения яблока
npm run build    # проверка типов + сборка в dist/
```

Нужен Node.js 20.19+ или 22.12+.

## Выложить на GitHub Pages

1. Создайте на GitHub пустой репозиторий (например, `apple`).
2. В папке проекта:
   ```bash
   git init -b main
   git add .
   git commit -m "Сайт про яблоко"
   git remote add origin https://github.com/ВАШ_ЛОГИН/apple.git
   git push -u origin main
   ```
3. В репозитории откройте **Settings → Pages → Build and deployment → Source** и выберите **GitHub Actions**.
4. Во вкладке **Actions** дождитесь зелёной галочки. Сайт появится по адресу
   `https://ВАШ_ЛОГИН.github.io/apple/`.

Дальше каждый `git push` в `main` публикует новую версию сам (см. `.github/workflows/deploy.yml`).
Если ваша основная ветка называется `master`, поправьте `branches: [main]` в этом файле.

Пути в сборке относительные (`base: './'` в `vite.config.ts`), поэтому менять конфиг под имя репозитория не нужно.

## Что где лежит

| Файл | Что делает |
| --- | --- |
| `src/App.tsx` | разметка страницы и все тексты разделов |
| `src/lib/varieties.ts` | сорта: названия, описания, цвета кожуры и румянца |
| `src/lib/appleGeometry.ts` | форма яблока, плодоножка, листик, раскраска |
| `src/Apple.tsx` | поведение яблока: вращение от прокрутки, переезд между сторонами, смена цвета |
| `src/Scene.tsx` | свет и окружение (световые панели, без загрузки HDR-картинок) |
| `src/lib/scrollState.ts` | положение прокрутки и курсора, которое читает анимация |
| `src/styles.css` | оформление |

## Как добавить сорт

Добавьте объект в массив в `src/lib/varieties.ts` (`ground` — основной цвет, `blush` — румянец, `blushAmount` — от 0 до 1), и кнопка появится сама.

## Источники данных на странице

Калорийность, вода и клетчатка: USDA FoodData Central (средние значения для сырого яблока с кожурой).
Производство: оценки FAO и USDA. Сорта, даты и география: общедоступные справочники по помологии.
